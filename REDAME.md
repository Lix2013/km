# KM

## koyot manager

هو مدير بكجات و مراقبة استهلاك الموارد و بواجهة عصرية قابلة للتخصيص


# نبدا الشرح باسم الله

## [-1-] auto setup

لعمل auto setup (لتجهيز ملفات الاعدادات و مسارات التطبيقات) ستفتح powershell على ويندوز او terminal على linux و اكتب
```
km auto-setup
```

## [-2-] start program
```
km start
```
